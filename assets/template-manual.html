撮影日ごとのフォルダへ

例：架空のツールコマンド・出力はすべて説明用
これは何か

入れたフォルダが、年／月に分かれる

5分で動かす

入れて、試して、本番の3回打つだけ

npm install -g photosort
← 横にスクロールできます →
まだいま実行中完了
ターミナル（出力は例）
覚えるルールは3つ

壊さないために、これだけ知っておく

1

まず --dry-run で確かめる

ファイルは動かない
2

写真はコピーでなく移動される

元の場所から消える--copy で残る
3

undo で直前の1回を戻せる

戻せるのは1回分
よくある使い方

やりたいことから選ぶ

日ごとに分けたい

photosort <フォルダ> --by day
2026/04/12/

元の写真も残したい

photosort <フォルダ> --copy
inbox/ はそのまま

別の場所へまとめたい

photosort <フォルダ> --to ~/Photos
~/Photos/2026/04/
困ったとき

エラーの文言から、対処まで1本道

症状撮影日が読めません: 12 枚
原因写真に撮影日の情報（EXIF）がない
確かめ方スクリーンショットや編集済みの画像か
対処--fallback mtime で更新日を使う
症状command not found: photosort
原因インストールが終わっていない
確かめ方npm ls -g photosort
対処上の「5分で動かす」を最初から
設定一覧

オプションは、変えたいときだけ

オプション初期値変わること
--dry-runなし移動の予定だけ表示する
--bymonthyear / month / day で分ける細かさ
--copyなし移動せずコピーする
--to入力と同じ場所整理先のフォルダ
--fallbackskip撮影日がない写真を mtime（更新日）で分ける
用語と FAQ

引っかかったら、ここだけ開く

EXIF とは？

カメラが写真に書き込む情報。撮影日時はここから読む。

同じ名前の写真があったら？

上書きせず、名前の末尾に -1, -2 を付けて置く。

動画も分けられる？

この例では写真（.jpg / .heic）のみ。動画は動かさない。
